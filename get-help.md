# Getting help and support for {{site.data.keyword.short_name}}
{: #get-help}

If you experience an issue or have questions when you're working in {{site.data.keyword.product_name}}, complete the following steps to debug the issue before opening an support case.

1. Check the [Status](https://cloud.ibm.com/status){: external} for service interruptions or outages.
1. Review the [Debugging guide](/docs/inference?topic=inference-ts-debug).
1. (Optional) If you're using model alignment, review the {{site.data.keyword.short_name}} artifacts and log files in your {{site.data.keyword.cos_full_notm}} [bucket](https://cloud.ibm.com/objectstorage/){: external}.
1. If you still can't resolve the problem, you can [create a support case](/docs/support?topic=support-open-case&interface=ui).
